# Setup

1. Unzip, then in the `portfolio` folder run:
   npm install
   npm run dev

2. Build for production:
   npm run build
   (output goes to the `dist` folder — deploy that to Vercel, Netlify, or Hostinger)

# What's inside
- React + Vite + Tailwind CSS
- Framer Motion animations throughout (hero text reveal, scroll reveals, hover micro-interactions)
- Bento-grid floating glass navbar
- Particle background hero (tsParticles) with mouse parallax
- Bento-grid Education & Projects sections
- Lenis smooth scrolling
- Custom animated cursor (desktop only)
- Real content already filled in: your name, skills, Appverse experience, BBIT education, your two AI/automation projects + Darbar-e-Madina + KaizenStage, and your real email/phone/GitHub/LinkedIn in Contact

# Easy edits
- Colors/fonts: tailwind.config.js
- Copy: each section's file in src/components/ (Hero.jsx, About.jsx, Education.jsx, Projects.jsx, Contact.jsx)
- Contact form currently just shows a "Message sent" state on submit — wire it to Formspree, EmailJS, or your own backend to actually receive messages
